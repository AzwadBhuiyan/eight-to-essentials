## [1.0.0] - 2026-10-22

First public release.

### Added

- Essential Eight self-check: all eight strategies, Maturity Levels One to Three, a chosen target level, ISM control IDs, plain-English questions, "why it matters" and evidence for every requirement.
- Context questions: organisation name, whether Essential Eight reporting is still required, and where systems mainly run (with a notice pointing SaaS and PaaS organisations to the ASD Essentials cloud chapter).
- Results: level per strategy, headline set by the weakest strategy, radar chart with a table alternative, prioritised action list, evidence request list and exceptions to review.
- ASD Essentials transition view: an indicative gap analysis by priority phase, domain, principle and action, built on ASD's mapping tables, plus the actions not covered by the Essential Eight.
- Printable report with cover, findings, actions, evidence list, exceptions, transition summary, method, sources and author footer.
- JSON export and import of answers (strictly validated) and CSV export of results (protected against formula injection).
- Demo mode with Swan River Analytics, a fictional company.
- About and Method and sources pages.
- Opt-in browser storage with "Clear my data".
- Strict Content Security Policy, CodeQL, Dependabot, pinned GitHub Actions, CI and GitHub Pages deployment.
- Unit, accessibility and security tests, and framework data validation.

### Data

- Essential Eight maturity model, November 2023.
- ASD Essentials for enterprise IT and its supporting documents, published 15 October 2026.
- Data checked on 20 October 2026.
